# Changement d'adresse (formulario en línea)

Campos del formulario (todos «(Nécessaire)» salvo indicación):

- Nom (Prénom / Nom)
- Courriel
- Téléphone
- Langue(s) parlée(s): Français / Anglais / Espagnol / Autres (+ campo «Préciser»)
- **Identifiant: los 3 primeros dígitos del NAS** (así identifican al salarié sin pedir el NAS completo)
- **Ancienne adresse**: adresse postale, no. appartement, ville, état/province/région, ZIP/code postal
- **Nouvelle adresse**: adresse postale, no. appartement, ville, province, code postal
- Spécifications (campo libre)

Se envía directamente desde la página web (no requiere cuenta del Portail).
